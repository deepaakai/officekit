3. Font Sizes — What to Use When

Font size (measured in points, abbreviated "pt") determines how large the text appears. The seven sizes available cover almost every use case:

  • 8pt: Footnotes, image captions, legal disclaimers.
  • 10pt: Dense technical documents, sidebars, code.
  • 12pt: Standard body text — the default for most documents.
  • 14pt: Subheadings, emphasis, easy-reading documents.
  • 18pt: Section headings, presentations.
  • 24pt: Chapter titles, large headlines.
  • 36pt: Cover page titles, posters.

Most professional documents use 12pt body text with headings ranging from 14pt to 24pt. Larger sizes are for emphasis, not body text.

4. PDF or Word — Which Should You Choose?

Both formats are useful, and the right choice depends on what you plan to do next:

  • Save as PDF if you want a document that looks identical on every device. PDFs lock the layout and are ideal for resumes, contracts, invoices, and finished reports.
  • Save as Word (.docx) if you plan to keep editing the document later, or need to send it to someone who will edit it in Microsoft Word, Google Docs, or LibreOffice.

You can export the same document in both formats — write it once, download it twice.

8. Best Practices for Clean Documents

  • Use Heading 1 for the main title of your document — it sets the outline level for navigation.
  • Use Heading 2 and Heading 3 for sections and subsections.
  • Keep paragraphs short — 3 to 5 lines each — for readability.
  • Use numbered lists for steps and bullet lists for unordered ideas.
  • Give your document a clear title before downloading.
  • Add an author name if you want your name to appear in the file's metadata.
  • Choose fonts wisely: Business → Calibri/Arial. Academic → Times New Roman. Modern → Georgia.
  • Stick to 12pt body text — larger sizes are for emphasis only.
  • Preview in PDF first if the layout matters.
  • Save both formats if you may need to edit the document later.

9. Troubleshooting Common Issues

  • Formatting lost in export? Headings, bold, italic, underline, and lists are all preserved. Complex nested tables are not supported — keep to simple lists.
  • PDF library not loading? Requires internet connection for the first load. After that, it caches.
  • Font not applying? Select the text first, then choose the font. Or select a font before typing.
  • Document too long? For 50+ page documents, use Word or Google Docs instead. This tool is optimized for documents up to ~20 pages.
  • Special characters missing? Basic Latin + common punctuation is supported. Complex scripts (Hindi, Chinese, Arabic) may not render in the PDF export.
