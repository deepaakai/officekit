PDF Locker & Unlocker — Password Protect and Unlock PDFs Online (2026)

DocEasy's PDF Locker & Unlocker is a single tool that does two jobs — add password protection to any PDF, or remove passwords from protected PDFs. Everything runs in your browser, so your sensitive documents never leave your device. Whether you're securing an e-Aadhaar download, unlocking a bank statement, or protecting a client proposal, this tool handles it in seconds.

Why Password-Protect a PDF?

PDFs are the universal format for sharing documents — but the wrong pair of eyes can cause real damage. Password protection solves that:

  • Aadhaar / PAN cards — Secure identity documents before emailing
  • Bank statements — Protect account numbers and balances
  • Legal contracts — Restrict editing, printing, or copying
  • Business proposals — Prevent unauthorized forwarding
  • Medical reports — Keep patient data confidential
  • Personal documents — Resume, mark sheets, tax returns
  • Client deliverables — Restrict copying or modifications

Why Unlock a PDF?

Password-protected PDFs are annoying when you legitimately own the document but don't want to type the password every time:

  • e-Aadhaar PDFs — Remove the DEEP1998-style password for easy access
  • PAN card PDFs — Remove the DOB-based password
  • Bank statements — Remove password for archiving or printing
  • Bulk merging — Unlock multiple files before combining them
  • Automation — Use in scripts that can't handle password prompts
  • Sharing with staff — Provide unprotected copies to trusted team members

  3. Step 3 — Click "Unlock & Download": The PDF is saved without password protection.

Common Password Formats in India

  • e-Aadhaar: First 4 letters of name in CAPS + birth year — e.g. DEEP1998
  • PAN card: Date of birth in DDMMYYYY — e.g. 15011998
  • Bank statements: Customer ID, DOB, or a combination
  • Credit card statements: Last 4 digits of card + DOB
  • Insurance policies: Policy number or DOB
  • Income tax returns: PAN number (lowercase) or DOB
  • Company documents: Usually sent separately by the provider

If none of the common formats work, check the email or SMS that delivered the PDF — the sender usually mentions the password there.

Frequently Asked Questions

What's the difference between PDF Locker and PDF Unlocker?

PDF Locker adds password protection to a PDF (encrypts it). PDF Unlocker removes password protection (decrypts it). Both are in the same tool — just switch tabs.

Are my PDFs and passwords safe?

Completely. Everything happens locally in your browser. Your file and passwords never leave your device. Verify with Developer Tools → Network tab — zero outgoing requests.

Can I password-protect a PDF without uploading it?

Yes — that's exactly how this tool works. The PDF never leaves your device. All encryption happens in your browser using JavaScript.

What's the difference between user password and owner password?

User password is required to open the PDF (everyone needs it). Owner password unlocks full access, including permissions you restricted (like printing or copying). If you don't set an owner password, the user password is used as the owner password too.

Can I restrict printing or copying?

Yes — after setting a password, you can uncheck "Allow printing" or "Allow copying text." Most PDF readers will respect these restrictions (though determined users can bypass them with specialized tools).

What password does e-Aadhaar use?

First 4 letters of your name in CAPITAL letters + your birth year. Example: name "Deepak" born 1998 → password DEEP1998. If your name has fewer than 4 letters, use the full name.

What password does PAN card PDF use?

Your Date of Birth in DDMMYYYY format. Example: DOB 15 January 1998 → password 15011998. If that doesn't work, try the PAN number itself or a combination of PAN + DOB.

I forgot the password — can I unlock without it?

No. PDF encryption is strong — without the password, the file can't be decrypted (that's the whole point of the security). If you've lost the password, contact the original sender, or try common formats listed above. There is no "bypass" for a truly strong password — anyone claiming otherwise is either scamming you or using brute-force tools that take days.

Will locking a PDF break it?

No. The PDF remains valid and opens normally in Adobe Reader, Chrome, Firefox, and every modern PDF reader. Only the password protection is added — content stays intact.

Does the locked PDF have a watermark?

No — never. DocEasy produces clean, watermark-free output. Your PDF looks identical to the original, just password-protected.

Can I remove permissions without a password?

No. If a PDF has permissions restrictions (like "no printing"), removing them requires the owner password. Enter it in the Unlock tab to save a fully unrestricted PDF.

What if the unlock fails with "wrong password"?

Double-check the password. Common issues: extra spaces, wrong case (CAPS vs lowercase), wrong format (DDMMYYYY vs MMDDYYYY), or a truly different password set by the original sender. Try the common patterns listed above — they cover 90% of Indian PDFs.

Does locking a PDF protect against hackers?

AES encryption (which we use) is strong — modern computers can't brute-force it in any reasonable time. However, if the password is weak (like "1234"), a dictionary attack can guess it. Use a strong password: 8+ characters with mixed case, numbers, and symbols.

Can I add a PDF to my digital signature workflow after locking?

No — locked PDFs must be unlocked first before adding digital signatures, form fields, or edits. Plan your workflow accordingly: sign first, then lock.

What if the original PDF is corrupted?

If the source PDF is corrupted, both lock and unlock will fail. Try opening it in a desktop PDF reader first to verify it works. If it opens fine there but fails here, report the file via the "Report Error" link.

Do you keep logs of my PDFs or passwords?

No. We don't log filenames, passwords, or content. Our analytics only records anonymous page views — never file activity. Since nothing leaves your browser, there's nothing to log.

Can I use this on mobile phones?

Yes — works on Android and iOS. The interface is touch-friendly. For very large PDFs, mobile devices have less RAM, so files under 100 MB work best.

How is this different from Adobe Acrobat's password protection?

Adobe Acrobat offers advanced features (certificate-based encryption, digital signatures). DocEasy uses AES-256 password encryption — the same algorithm Adobe uses for basic password protection. For 99% of use cases, DocEasy's encryption is more than sufficient.
