Universal Media Editor — Frequently Asked Questions

Everything about editing video and audio in your browser — trim, mute, compress, convert, and more.

What can I do with this Universal Media Editor?

This single tool replaces 12 separate media utilities. You can: (1) Trim — cut video or audio to exact start and end times; (2) Mute — remove the audio track completely while keeping video; (3) Compress — reduce file size with three quality presets; (4) Resize — change resolution to any width and height you specify; (5) Rotate — turn video 90°, 180°, or 270° to fix orientation issues; (6) Flip — mirror horizontally or vertically for creative effects; (7) Speed — speed up or slow down from 0.25× to 4×; (8) Loop — repeat the video 2 to 10 times in a single file; (9) Reverse — play video and audio backwards; (10) Extract Audio — pull the audio track from any video as MP3, WAV, OGG, or M4A; (11) Convert — change format to MP4, WebM, animated GIF, or MP3; (12) Extract Frames — export JPG stills from any video. Every operation runs entirely in your browser using FFmpeg compiled to WebAssembly — nothing is uploaded to any server.

How does the processing work without a server?

This tool uses FFmpeg compiled to WebAssembly — the same engine used by professional video software, but running entirely inside your browser. When you drop a file, it's loaded into your browser's memory. FFmpeg then processes it using your device's CPU to perform trimming, conversion, compression, and all other operations. The output is written to a new file in memory and offered to you as a download. At no point does any data leave your device — no uploads, no cloud processing, no server queue, no waiting for someone else's computer. This is why the first use takes about 10 seconds (loading the FFmpeg engine for the first time), but subsequent operations are much faster because the engine is already cached.

Which file formats are supported?

Input formats include MP4, WebM, MOV, MKV, AVI, FLV, TS, M4V, and 3GP for video, plus MP3, WAV, OGG, OPUS, M4A, AAC, FLAC, and WMA for audio. Output formats depend on which tool you use: Trim, Mute, Compress, Resize, Rotate, Flip, Speed, Loop, and Reverse all output MP4 (video) or MP3 (audio); Extract Audio outputs MP3, WAV, OGG, or M4A based on your selection; Convert outputs MP4, WebM, GIF, or MP3; Extract Frames outputs a series of JPG images. The tool auto-detects the input format from the file extension, so you don't need to specify it manually. If a file doesn't work, try converting it to a standard format first using the Convert tab.

How do I trim a video to a specific time range?

Click the "Trim" tab, then enter your start and end times. The format is HH:MM:SS (hours:minutes:seconds) or you can use plain seconds. For example, to cut from 1 minute 30 seconds to 2 minutes 45 seconds, enter 00:01:30 as start and 00:02:45 as end. Leave the end field blank to trim from start to the end of the video. Click "Process File," and the trimmed clip downloads in seconds. The trim is frame-accurate and, for MP4/H.264 files, lossless — no quality loss because we cut at keyframe boundaries without re-encoding. This makes Trim one of the fastest operations, usually completing in 1–3 seconds even for large files.

Does compressing a video reduce quality?

It depends on the preset you choose. "Light" (CRF 28) keeps most of the original quality while reducing file size by 30–50%. "Balanced" (CRF 32) reduces size by 50–70% with slight quality loss that's usually invisible for social media sharing. "Strong" (CRF 36) reduces size by 70–85% with visible compression artifacts — good for rough previews but not for final outputs. For WhatsApp, Instagram, Telegram, or email sharing, "Balanced" is the sweet spot. For archiving, use "Light." You can also combine compress with resize — reducing 4K to 1080p plus CRF 32 gives dramatic size savings with minimal visual impact.

How do I extract audio from a video as MP3?

Click the "Audio" tab, select MP3 as the output format and 192 kbps bitrate (recommended for music) or 128 kbps (fine for voice). Drop your video file, click Process. In a few seconds you'll get an MP3 file containing only the audio track. This works on MP4, MOV, MKV, AVI, WebM, and any video format FFmpeg supports. The audio quality matches the original — no re-encoding degradation for MP3 sources. If you need lossless audio, choose WAV output instead; the file will be larger but bit-perfect. For voice recordings, 64 kbps is plenty. For music, use 192 kbps or higher.

Can I convert video to GIF?

Yes — click the "Convert" tab, choose "Animated GIF" as the output format, and click Process. The tool generates a GIF from your video. Note that GIFs are limited to 256 colors and don't support audio, so quality is lower than video. For best results, use short clips (under 10 seconds), and consider trimming first using the Trim tab. GIF output files can be surprisingly large — a 5-second 720p GIF can be 5–10 MB. If you need a smaller GIF, reduce the resolution first using the Resize tab, then convert. The tool automatically applies a 10 fps frame rate and 480px width for GIFs to keep file size reasonable.

What's the maximum file size I can process?

There's no hard limit imposed by DocEasy, but practical limits depend on your device's RAM. Devices with 4 GB RAM handle up to about 200 MB comfortably. 8 GB RAM handles 500 MB. 16 GB RAM handles 1 GB or more. Since everything runs in your browser's memory, very large files may temporarily slow down your device. For files above 500 MB, close other browser tabs and apps first, and use Chrome or Edge — they handle WebAssembly memory more efficiently than Firefox. If a file is too large, trim it down first using a desktop tool, then process the smaller clip here.

How long does processing take?

Simple operations like trim (lossless), mute, rotate, and flip complete in 1–3 seconds regardless of file size. Compress, resize, and convert take 10–60 seconds for a typical 100 MB file, depending on your CPU. Complex operations like reverse, speed change, and GIF conversion take longer — up to 2–3 minutes for a 100 MB file. The first operation in a session also includes a one-time ~10-second FFmpeg engine load. Subsequent operations in the same session skip this step. If a file takes more than 5 minutes, your device is likely memory-constrained — try a smaller file or close other apps.

Does the tool work offline?

Partially. The FFmpeg WebAssembly engine loads once from a CDN (about 25 MB). After that first load, the engine is cached by your browser, and the tool works offline for subsequent uses. So: (1) First visit — requires internet to download FFmpeg; (2) Subsequent visits — works fully offline, even with Wi-Fi off. You can verify this by loading the page, processing a file, then turning off Wi-Fi and processing another file — it will still work. This makes DocEasy ideal for flights, rural areas, or privacy-conscious environments where you don't want any network activity during editing.

Why is my output file larger than expected?

Several reasons can cause this: (1) Converting MP4 to WebM often produces larger files — WebM VP9 is not always more efficient than H.264; (2) Re-encoding can increase bitrate if the preset is too high quality; (3) Lossless trim preserves the original bitrate, so if the source was a high-bitrate 4K video, output will be large too; (4) GIF conversion is inherently large due to the format's inefficiency; (5) Audio extraction to WAV is uncompressed and much larger than MP3. To reduce size: use Compress with a higher CRF (like 32), reduce resolution to 720p first, and use MP4 (not WebM) for maximum compatibility and efficiency.
