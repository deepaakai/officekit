Complete Guide: Type in Hindi, English and Hinglish with Word Writer (2026)

Writing a document used to require installing Microsoft Word on a computer — and typing in Hindi required an external keyboard, a transliteration tool, or hours of practice with a Devanagari layout. Today, both problems are solved. DocEasy Word Writer lets you write in Hindi, English, or Hinglish with 13 fonts and a built-in Hindi keyboard, right in your browser. When you are done, export as Word (.docx) or PDF — no signup, no upload, 100% private.

This complete guide covers every feature: how to write in the language you want, how the Hindi keyboard functions, which fonts to use, and best practices for creating clean documents.

Write in Hindi, English, or Hinglish — export as Word or PDF. 100% private, 100% free.

1. Quick Start — 60 Seconds to a Ready Document

If you need to type something quickly and print or send it, follow these steps:

  1. Open the page — the editor is right there. Click and start typing.
  2. Type in any language — English, Hindi, or mixed. The editor never restricts what you type.
  3. Toggle Header / Footer (optional) — flip the switches above and below the editor and type your header / footer text.
  4. Format — use the toolbar for font, size, color, alignment.
  5. Export — click Save Word or Save PDF. The file downloads instantly.

That's it. No signup, no upload, no watermark. Everything happens in your browser.

2. Writing in Any Language — No Mode Required

The editor is language-agnostic. You can type English letters, Devanagari characters, or a mix of both in the same document. There is no "language mode" to switch — just write whatever you want, in whichever script you want.

  • English — type normally on your keyboard
  • Hindi — click the orange हिन्दी button in the toolbar to open the on-screen Devanagari keyboard, then click characters to insert them. On mobile, use your device's built-in Hindi keyboard.
  • Hinglish (English → Hindi) — type phonetically in English letters like namaste or bharat. The editor converts them to Hindi automatically. No mode toggle needed — the conversion happens naturally.

You can also paste Hindi text from anywhere (WhatsApp, Gmail, Google Translate) directly into the editor and it stays as-is.

3. Hindi Virtual Keyboard — How to Use

Click the orange हिन्दी button in the toolbar. A virtual keyboard slides open below the editor. It has five sections:

  • Vowels (Svar) — 13 independent vowels: अ, आ, इ, ई, उ, ऊ, ऋ, ए, ऐ, ओ, औ, अं, अः
  • Consonants (Vyanjan) — 36 consonants + conjuncts: क, ख, ग, घ, च, छ, ज, झ, ट, ठ, ड, ढ, त, थ, द, ध, न, प, फ, ब, भ, म, य, र, ल, व, श, ष, स, ह, क्ष, त्र, ज्ञ
  • Matras (Vowel Signs) — 14 vowel marks: ा, ि, ी, ु, ू, ृ, े, ै, ो, ौ, ं, ँ, ः, ्
  • Numbers (Ank) — ० to ९
  • Punctuation (Viram) — पूर्ण विराम (।), comma, semicolon, question mark, backspace, enter, space

How to type: place your cursor in the editor, then click any key. The character is inserted at the cursor. The keyboard remembers your last cursor position even if you click elsewhere first.

How to add matras: click the consonant first, then the matra. For example, to type का, click क then ा. For कि, click क then ि. For क्ष, click the conjunct key directly.

On mobile: the virtual keyboard does not open automatically — your device's own Hindi keyboard is much faster. Add Hindi in Settings → Language, then press the globe icon on your keyboard to switch.

5. Fonts — The Right Font for Each Language

The Font dropdown groups English and Hindi fonts separately:

English Fonts (8):

  • Calibri — modern, professional. Default choice.
  • Arial — universal sans-serif, works on every device.
  • Times New Roman — classic serif, best for academic papers.
  • Georgia — screen-friendly serif, great for long documents.
  • Verdana — wide sans-serif, excellent for small text.
  • Tahoma — compact, good for dense layouts.
  • Lora — elegant serif, ideal for essays and blogs.
  • Courier New — monospaced, used for code and technical docs.

Hindi Fonts (5):

  • Noto Sans Devanagari — Google's modern Hindi font, most readable.
  • Noto Serif Devanagari — serif variant, formal documents.
  • Baloo Bhai 2 — bold, playful, for headings and posters.
  • Hind — Indian Type Foundry's popular font, ideal for body text.
  • Mangal — the traditional Windows Hindi font.

How to apply: select text (or place the cursor) and choose a font from the dropdown. It applies immediately to the selection and to anything you type next. Font is applied per character, so you can mix English and Hindi fonts in the same document.

6. Font Size — From 6pt to 48pt

The size dropdown has 14 options. Common uses:

  • 6pt – 8pt — footnotes, legal disclaimers, captions
  • 9pt – 11pt — dense documents, sidebars, tables
  • 12pt — standard body text (default)
  • 14pt – 18pt — subheadings, emphasis
  • 20pt – 24pt — section headings
  • 32pt – 48pt — cover page titles

7. Colors — Text and Highlight

Two color pickers sit in the toolbar:

  • Text Color (A icon) — changes the text color. A colored line below the icon shows the current color.
  • Highlight (marker icon) — adds a background color behind the text.

Click the icon → system color picker opens → choose a color → applies instantly. Default text color is black; default highlight is yellow.

To show colors in print: enable "Background graphics" in the print dialog. Otherwise colors appear on screen but not on paper.

8. Header and Footer — With Toggle Switches

Two toggle switches sit above and below the editor — one for the Header, one for the Footer.

  • Toggle OFF (default) — the row is dimmed, the input is disabled, and nothing appears in print or PDF. Perfect when your document does not need a header/footer.
  • Toggle ON — the input becomes editable. Type your text and it appears above/below the editor on screen, at the top/bottom of every printed page, and in the exported PDF.

What to put in Header: company name, document title, date, reference number.
What to put in Footer: page number, contact info, copyright, confidentiality note.

9. Templates — One-Click Documents

Six ready-made templates sit above the toolbar:

  • Blank — empty document (default)
  • Letter — formal letter: sender address, date, recipient, subject, body, signature
  • Application — standard leave / request application format
  • Resume — professional resume: summary, experience, education, skills
  • Notice — office/school notice format with reference number and signature
  • Essay — essay structure: introduction, body, conclusion

Clicking a template replaces the editor content and auto-fills header/footer if enabled. Any [square brackets] in the template are placeholders — replace them with your own details.

10. Print — Clean Output

The Print button opens your browser's print dialog. Only your document, plus the enabled header and footer, appear on the printed page. The toolbar, template bar, virtual keyboard, and status bar are hidden automatically. A4 paper size, 20mm margins, professional layout.

You can also press Ctrl+P (Cmd+P on Mac) — same result.

11. Save as PDF

The Save PDF button opens the same print dialog — just pick "Save as PDF" as the destination (Windows: "Microsoft Print to PDF", Mac: "Save as PDF", Chrome: "Save as PDF").

Big advantage: the exact fonts you see on screen (Noto Devanagari, Mangal, Baloo, Lora, everything) are embedded into the PDF. The PDF shows the same fonts on any device, whether or not those fonts are installed there.

12. Save as Word (.docx)

The Save Word button creates a real .docx file that:

  • Opens in Microsoft Word, Google Docs, LibreOffice, and Apple Pages
  • Preserves fonts, sizes, colors, and highlights
  • Stores header and footer as real Word header/footer (only if enabled)
  • Converts headings into real Word heading styles (navigation pane works)
  • Renders Hindi text correctly on any system

Note: .docx files do not embed font files (browsers don't have them). If the receiver doesn't have the font installed, Word uses its default — but Hindi characters still display correctly because every system has a Devanagari fallback. Google Docs renders it perfectly.

13. Autosave — No Lost Work

Everything you type saves to your browser's localStorage every 600 milliseconds. Close the tab, come back — your content is there. Saved only on your device, never on a server. Auto-cleanup after 7 days.

14. Dark Mode

The site header includes a sun/moon toggle. Click it to switch between light and dark themes. The preference is saved in localStorage.

16. Frequently Asked Questions

Is the tool really free?

Yes — 100% free. No signup, no watermark, no daily limit. Everything runs locally in your browser.

Can I type Hindi on mobile?

Yes. On mobile the virtual keyboard does not open automatically. Add Hindi in your device's Settings → Language, then press the globe key on your keyboard to switch to Hindi.

Why does the Hindi keyboard open from a button instead of automatically?

Because the toolbar button gives you full control — open it only when you need Devanagari characters. When closed, it stays out of the way.

How does Hinglish conversion work?

Common English-to-Hindi phonetic patterns — like namaste → नमस्ते, bharat → भारत, dhanyavad → धन्यवाद. Consonants, vowels, matras, and conjuncts are all handled. Anything not recognized stays in English, giving you mixed output.

Is my data uploaded anywhere?

No. Everything happens locally in your browser. No server call is made. When you close the tab, content is cleared from memory (the localStorage copy remains on your device).

Will Hindi render correctly in the PDF?

Yes. The Save PDF button opens the print dialog — the fonts you see on screen are embedded into the PDF. Noto Sans Devanagari, Mangal, Baloo — all render correctly.

Will the .docx open in Google Docs?

Yes. The file is standard Word format — opens in Google Docs, Microsoft Word, LibreOffice Writer, and Apple Pages. Hindi text stays intact.

How do I enable / disable the header?

Flip the toggle switch to the left of the "Header" label above the editor. OFF = header hidden everywhere (screen, print, PDF, .docx). ON = header appears on every printed page.

How do I enable / disable the footer?

Same as the header — flip the toggle switch below the editor. OFF by default.

Does header/footer repeat on every page?

Yes, when enabled. In print and PDF, on every page. In .docx, it is saved as a real Word header/footer, so Word also repeats it on every page.

Can I mix Hindi and English in one document?

Yes. Type English normally, paste Hindi from anywhere, or use the Hindi keyboard to insert Devanagari. Both stay in the same document, with their own fonts.

Why does the font size go down to 6pt?

Legal disclaimers, footnotes, and terms & conditions. Also useful when you need to fit a lot of content on an A4 page. 12pt is the default and standard body size.

Does it work offline?

After the page has loaded once, yes. The .docx export library needs to load on first use (the browser caches it, then it works offline too).

Colors don't appear in print — what do I do?

Enable "Background graphics" in the print dialog (under More settings). Browsers skip background colors by default to save ink.

Can I create custom templates?

Everything you write is autosaved. So build your structure once, save it, and edit the same content next time. Custom templates aren't a separate feature yet, but you can save your file as .docx and reopen it.
