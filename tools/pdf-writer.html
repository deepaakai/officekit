2. Writing in Any Language — Roman & Devanagari Integration

The editor supports seamless switching between Roman (English) script and Devanagari (Hindi) script. You can type English letters, Devanagari characters, or a mix of both in the exact same line.

  • Roman (English) Mode: Select fonts like Calibri, Arial, Times New Roman, or Lora. The editor types standard alphanumeric text with high precision.
  • Devanagari (Hindi) Mode: Select Noto Sans Devanagari, Hind, or Baloo Bhai 2. Click the orange हिन्दी button in the toolbar to access full virtual vowels and consonants.
  • Hinglish (Phonetic Auto-Conversion): Type phonetically in English letters (e.g., namaste, bharat, mera). The engine automatically replaces recognized words with their Devanagari counterpart.

3. Hindi Virtual Keyboard — How to Use

Click the orange हिन्दी button in the toolbar. A virtual keyboard slides open below the editor. It contains vowels (अ to अः), consonants (क to ज्ञ), matras, and numbers.

How to add matras: click the consonant first, then the matra. For example, to type का, click क then ा. For कि, click क then ि.
