All Categories — Frequently Asked Questions

Everything about DocEasy's tools — categories, privacy, formats, and how to get the most out of them.

What is DocEasy?

DocEasy is a free, browser-based suite of 35+ tools for handling PDFs, images, documents, ID cards, media files, and everyday utilities. Every tool runs entirely in your browser using modern web technologies like Canvas, WebAssembly, MediaRecorder, and the File API. This means nothing is ever uploaded to any server — your files stay on your device from start to finish. DocEasy is designed for students, professionals, eMitra/CSC operators, teachers, content creators, and anyone who needs reliable document and media tools without installing software, creating an account, or paying a subscription.

Are all DocEasy tools really free?

Yes — every single tool on DocEasy is 100% free, forever. There's no signup, no email, no watermark, no daily limit, no file-size cap, and no premium tier hiding behind a paywall. You can use any tool as many times as you want, on any device, forever. The site is supported by lightweight, non-intrusive display ads on some pages. We don't sell your data, we don't track your files, and we don't ask for your email to unlock features. Every feature is available to every visitor with zero restrictions.

How many categories and tools does DocEasy have?

DocEasy currently organizes its tools into 8 main categories: PDF Tools (8 tools), Image Tools (4 tools), ID & Signature Tools (6 tools), Media Tools (7 tools), Printing Tools (10+ tools), File Converters (4 tools), and Utility Tools (6 tools). That's over 35 individual tools, all running locally in your browser. We're actively adding new tools every month — recent additions include the Screen Recorder, Voice Recorder, Text to Speech, Meme Generator, and Universal Media Editor.

Are my files uploaded to any server?

Never. Every DocEasy tool runs entirely client-side in your browser. When you drop a file, it's read into your browser's memory using the FileReader or File APIs. All processing — whether that's merging PDFs, compressing images, cropping ID cards, or recording audio — happens locally on your device. When you click Download, the result is written back to your device. You can verify this yourself: open Developer Tools (F12), go to the Network tab, and process a file. You'll see zero outgoing requests carrying your data. This is a technical impossibility for us to see your files, not just a policy promise.

Do I need to create an account?

No — you never need to create an account, provide an email, or log in. Every tool on DocEasy works completely anonymously. This is by design: we believe privacy-first tools shouldn't require you to surrender personal information just to use them. Open any tool page, use it, and close the tab — there's no trace of your activity anywhere on our end (because we don't log it) or on your device (because nothing is stored beyond the browser's session memory).

Do these tools work on mobile phones?

Yes — every DocEasy tool is fully responsive and works on Android phones, iPhones, iPads, and tablets. The interface adapts to narrow screens with touch-friendly controls and larger tap targets. Some tools (like Screen Recorder) have limited mobile support due to OS restrictions, but most tools work perfectly on mobile. For best results with media-heavy tasks like video editing, use a desktop or laptop with 8 GB+ RAM. For quick tasks like image resizing, PDF merging, or signature cropping, mobile works great.

Which browsers are supported?

All modern browsers: Google Chrome 90+, Microsoft Edge 90+, Mozilla Firefox 88+, Safari 14+, Brave, Opera, Vivaldi, and all Chromium-based browsers. Chrome and Edge offer the smoothest experience for most tools, especially those using WebAssembly (like the Universal Media Editor) or advanced APIs (like Screen Recorder, Voice Recorder, and Text to Speech). Firefox works well too but may be slightly slower for large files. Safari supports everything but sometimes has subtle differences in PDF rendering and audio recording formats.

Can I use DocEasy tools offline?

Partially. After you load a tool page once, most tools continue working even without an internet connection — because all processing happens locally in your browser. You can switch off Wi-Fi and still resize images, crop PDFs, record voice, or process files. The only exception is tools that load additional WebAssembly modules on first use (like the Universal Media Editor's FFmpeg engine, ~25 MB) — those need one online load, after which they're cached by your browser and work offline for subsequent visits.

With DocEasy, you can verify the privacy claim yourself: open Developer Tools, watch the Network tab, and see that zero data is transmitted during processing. For eMitra and CSC operators handling hundreds of customer documents daily, DocEasy is the safest choice.

What file sizes can DocEasy handle?

It depends on the tool and your device's RAM. General guidelines: lightweight tools (image resize, PDF merge, QR generator) handle files up to 100 MB easily. Medium tools (image compression, PDF compression, ID card cropping) handle 200–500 MB on modern devices. Heavy tools (video editing, screen recording, audio extraction using FFmpeg WebAssembly) handle 500 MB–1 GB on 8–16 GB RAM devices. If a file crashes your browser, try closing other tabs, using a smaller file, or switching to Chrome or Edge (which handle WebAssembly memory best).

Can I process multiple files at once?

Some tools support batch processing, others are one-file-at-a-time. Batch-supporting tools include: Image Compressor, Image Converter, and Video Converter (in the Universal Media Editor). One-file tools: PDF Merge (takes multiple, outputs one), ID Card Cropper, Screen Recorder, Voice Recorder, and most Printing Tools. If you need heavy batch processing (20+ files), we recommend FFmpeg on desktop for video/audio or ImageMagick for images — DocEasy is optimized for one-off, quick tasks rather than industrial-scale batch work.

Do you offer an API for developers?

Not currently. All DocEasy tools are designed for human use through the web interface, not for programmatic access. If you need to process documents or media programmatically, we recommend: PDFs: PDFtk, Ghostscript, or Python's PyPDF2 library. Images: ImageMagick, Sharp (Node.js), or Python's Pillow. Video/Audio: FFmpeg (command-line). ID card cropping: OpenCV or Pillow in Python. These open-source tools are more powerful than our browser-based tools for programmatic use. DocEasy is built for humans who want privacy-first, no-install tools.
