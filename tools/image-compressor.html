1. Image Resizer — Set Exact Dimensions

The Resize tab lets you resize images to exact dimensions in five different units, plus a target file size option. This is essential when a portal demands specific pixel dimensions.

Supported Units

  • Pixels (px) — Most common for portal uploads and web images. Example: 600 × 600 px, 1920 × 1080 px.
  • Centimeters (cm) — Physical measurements for passport photos and ID cards. Example: 3.5 × 4.5 cm.
  • Millimeters (mm) — Standard for exam photo requirements. Example: 35 × 45 mm.
  • Inches (in) — US and international visa photos. Example: 2 × 2 inches.
  • Target File Size (KB) — Directly target a KB limit without specifying dimensions.

DPI Selection for Physical Sizes

When you use centimeters, millimeters, or inches, the DPI (Dots Per Inch) value determines the print resolution. The tool offers five presets:

  • 96 DPI — Screen only (web, email)
  • 150 DPI — Basic print quality
  • 200 DPI — Good print quality
  • 300 DPI — Professional print (passport, exams) — Recommended
  • 600 DPI — Ultra HD print (specialized)

For any government form, exam photo, or ID card, always choose 300 DPI. It's the universal print standard and matches what printers and Photoshop expect.

2. Image Compressor — Reduce File Size Intelligently

The Compress tab uses adaptive JPEG encoding. It starts at your chosen quality level (default 80%) and progressively reduces quality until your target KB is reached. This means you get the highest possible visual quality within your file size limit.

Compression is essential for:

  • Email attachments — Gmail's limit is 25 MB
  • Portal uploads — Most have strict 50 KB or 100 KB limits
  • Website performance — Smaller images load faster
  • Storage savings — Compress photos before archiving

3. Format Converter — JPG, PNG, WEBP

Different platforms require different formats. The Format tab lets you convert between the three most common web image formats:

  • JPEG / JPG — Best for photographs. Small file size. No transparency. Universal support.
  • PNG — Lossless quality. Supports transparency. Larger file size. Best for screenshots, logos, graphics.
  • WEBP — Modern format. Smaller than JPG at same quality. Supported by all modern browsers. Google's preferred format.

Each format supports quality selection (100%, 90%, 80%, 70%), so you can balance visual quality against file size.

6. Image to Text (OCR)

The OCR tab extracts text from images using Tesseract.js — a JavaScript port of the popular Tesseract OCR engine, trained on hundreds of thousands of fonts. It works on:

  • Scanned documents — Convert paper documents into editable text
  • Screenshots — Extract text from images you can't copy
  • Book pages — Digitize printed text for research
  • Receipts and invoices — Pull data from paper records
  • Business cards — Extract contact information
  • Signboards and notices — Read printed signs from photos

Best results with: Clear printed text, good lighting, high contrast, straight orientation. Handwritten text and cursive fonts produce lower accuracy — this is a limitation of all OCR engines, not just ours.

Frequently Asked Questions

What image formats can I upload?

JPG, JPEG, PNG, WEBP, GIF, and BMP. All common web image formats are supported.

How do I resize an image to exactly 50 KB?

Open the Resize or Compress tab, click the "50 KB" preset pill, upload your image, and click Resize/Compress & Download. The tool automatically adjusts quality to hit your target.

Does resizing affect image quality?

Resizing uses high-quality canvas rendering. Small upscales look sharp; large upscales may soften. Compressing always reduces quality slightly — the amount depends on how aggressive your target size is.

What's the difference between resize and compress?

Resize changes the pixel dimensions (width × height). Compress reduces the file size in KB while keeping the original dimensions. Both can be done in this tool.

Can I convert PNG to JPG?

Yes. Go to the Format tab, upload your PNG, select JPEG as the target, choose quality, and click Convert.

Can I create a PDF from multiple photos?

Yes. The "Images → PDF" tab accepts multiple files and exports them as a single multi-page PDF using your browser's print-to-PDF feature.

How accurate is the OCR feature?

95–99% on clean printed English text. Lower accuracy on handwriting, low-resolution scans, or non-English languages. English is fully supported; more languages coming soon.

Is there any file size limit?

No hard limit. Very large images (over 20 MB) may take longer to process depending on your device's RAM.

Does this work on mobile?

Yes. All functions work on any modern mobile browser — Android, iOS, or tablet. The interface is fully responsive and touch-enabled.

Are my files uploaded anywhere?

No. All processing happens locally in your browser. Your files never leave your device.

Pro Tips for Best Results

  • Start with the original photo — Don't re-resize an already-resized image. Compressing always degrades quality slightly; the fewer times you compress, the better the final result.
  • Use 300 DPI for print — If your photo will be printed at any point, set DPI to 300. It's the universal standard.
  • Preview before download — The tool shows you a live preview before generating the final file. Zoom in to check details.
  • Batch efficiently — For multiple files, resize them all with the same setting, then download in a batch.
  • Keep originals — Always keep the original high-resolution photo before resizing or compressing. You can always resize down, but upscaling never fully recovers lost detail.
  • Use WebP for websites — WebP files are 25–35% smaller than JPG at the same visual quality, and every modern browser supports them.
