What is PDF Splitting?

PDF splitting is the process of separating a single PDF file into two or more smaller PDF files. There are two common split types:

  • Split into individual pages: Every page of the source PDF becomes its own separate PDF file. A 20-page PDF becomes 20 one-page PDFs.
  • Split by page range: Extract only specific pages or ranges into a single new PDF. For example, pages 3–7 of a 100-page document become a 5-page PDF.

Both types are supported by DocEasy's Split PDF tool. You choose which mode you want before processing — the tool handles all the underlying PDF structure manipulation using pdf-lib, a powerful open-source JavaScript library that operates entirely inside your browser.

Page Range Syntax — How to Specify Pages

The range input accepts flexible comma-separated syntax:

  • 1 — Extract only page 1
  • 1-5 — Extract pages 1 through 5 (inclusive)
  • 1-3, 5, 7-10 — Extract pages 1, 2, 3, 5, 7, 8, 9, 10
  • 10-1 — Reversed ranges work too (same as 1-10)
  • 1, 1, 1, 5 — Duplicates are ignored automatically

Out-of-range pages (like page 999 in a 20-page PDF) are silently skipped. Invalid input like abc or 1--3 is ignored, and only valid pages are extracted.

Troubleshooting Common Issues

Issue 1: "Error while splitting: Failed to parse PDF"

Your PDF file may be corrupt or use an unsupported encryption. Try opening the PDF in a regular viewer to confirm it displays correctly. If it opens fine elsewhere, try saving it via "Print to PDF" and retry — sometimes this normalises odd PDF structures.

Issue 2: Output PDFs Are Blank

Some PDFs use unusual structures that pdf-lib can't fully reproduce. Try the "Extract page range" mode with a smaller set of pages to isolate the issue. If specific pages fail, the source PDF may use vector streams that pdf-lib doesn't support.

Issue 3: Browser Freezes on a Large File

Close other browser tabs and heavy applications. If the freeze persists, use a smaller PDF. For very large documents (500 MB+), a desktop tool like PDFtk or QPDF handles better than a browser-based one.

Issue 4: Download Buttons Don't Work

Some browsers block programmatic downloads from local blobs. Try right-clicking the Download button and choosing "Save link as", or disable popup/download blockers for this site.

Issue 5: Extracted PDFs Are Larger Than Original

Every split PDF re-saves the entire document structure, which can slightly increase size for tiny files. For large files, the size difference is negligible. If file size matters, run the output through our Compress PDF tool.
