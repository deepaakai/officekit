How do I crop a customer's Aadhaar card to the correct size?

Use the ID Card Dual-Side Cropper tool — it's designed specifically for this. Steps: (1) Open the tool and drop your customer's Aadhaar PDF or scanned image. (2) If the PDF is password-protected (common for e-Aadhaar downloads), enter the password. The common format is the first 4 letters of the name in CAPITALS + birth year (e.g., "DEEP1998" for Deepak born in 1998). (3) Two crop boxes appear — a green one for the front and a blue one for the back. Position each box over the corresponding side of the card. (4) The default size is 8.5 × 5.5 cm (CR80 standard, same as a credit card). This is what banks and KYC portals require. (5) Click "Print Ultra HD" to print both sides side-by-side on A4 at 300 DPI. Or click "Save HD Images" to download the front and back as separate PNG files. Both sides print at exactly 8.5 × 5.5 cm — no measuring, no manual scaling, no errors.

What is the correct Aadhaar card size for printing?

The standard Aadhaar card follows the international CR80 standard — 8.5 × 5.5 cm (85.6 × 54 mm), the same size as a credit card. This is the size required by banks, SIM card vendors, and KYC verification portals. Some portals (like UTIITSL for PAN card KYC) ask for slightly different sizes — 8.6 × 5.4 cm for KYC submission. The ID Card Cropper allows you to adjust the dimensions in the toolbar if needed. Always print at 100% scale — never "fit to page" or "shrink to fit", which automatically resizes to fit margins and produces incorrect card sizes. After printing, measure with a ruler to verify exact 8.5 × 5.5 cm before submitting to the customer. Common mistake: operators use "fit to page" and print cards that look correct but are 5–10% smaller — leading to KYC rejections. DocEasy defaults to the correct size and disables auto-scaling in print output.

How do I resize photos for online application forms?

Most government portals (SSC, UPSC, NEET, JEE, IBPS, RRB, state PSCs) have specific photo size requirements: typically 200 × 230 pixels at 20–50 KB in JPG format for signatures, and 4 × 3 cm at 20–100 KB for photos. The Photo Size Resize tool lets you: (1) Upload the customer's photo; (2) Select the exact dimensions required (or type custom values); (3) Set the target file size in KB (e.g., "Max 50 KB"); (4) The tool automatically crops, resizes, and re-compresses the JPEG to hit your target; (5) Download the result — ready to upload. This eliminates the trial-and-error of manually resizing in MS Paint or Photoshop, where operators often struggle to hit exact file size limits. DocEasy handles all the math in seconds. The tool supports multiple presets for common exams (SSC CGL, UPSC IAS, NEET UG, etc.) plus custom dimensions.

Can I scan paper documents using my phone?

Yes — the Document Scanner tool turns your phone into a portable scanner. Steps: (1) Open the tool on your phone; (2) Take a photo of the document (Aadhaar, PAN, Voter ID, Ration Card, etc.) using your phone's camera; (3) The tool auto-detects the document edges and straightens the perspective (perspective correction); (4) It enhances contrast, removes shadows, and produces a clean black-and-white or grayscale scan; (5) Save as PDF or JPG. This is far faster than using a flatbed scanner — especially useful for eMitra operators who process dozens of documents daily. The scan quality is comparable to a desktop scanner at 300 DPI. For best results: place the document on a flat, matte surface (not glass), use natural daylight rather than flash, and hold the phone directly above the document (not at an angle).

How do I merge multiple customer documents into one PDF?

Use the Merge PDF tool. Steps: (1) Open the tool; (2) Drop 2 or more PDF files (e.g., Aadhaar front PDF + Aadhaar back PDF + PAN PDF + bank statement PDF); (3) Drag to reorder them if needed; (4) Click "Merge" — the tool combines them into one PDF in seconds; (5) Download the merged PDF. This is useful when portals require a single file upload combining multiple documents (common for loan applications, KYC submissions, scholarship applications, exam registrations). The merge happens entirely in your browser using PDF-lib — no server round-trip, no waiting. You can merge 2 files or 50 files in one go. File order is preserved exactly as you arrange them.

Can I compress files to meet portal upload limits?

Yes — this is one of the most common tasks in service centers. Most government portals have strict upload limits: 50 KB, 100 KB, 200 KB, or 500 KB depending on the document. The Compress PDF tool reduces PDF file size by 60–90% using image downsampling and re-encoding. The Image Compressor tool reduces JPG/PNG file size by 50–90% using adjustable quality. For example: a 2 MB Aadhaar PDF can be compressed to 150 KB without visible quality loss. A 5 MB photo can be compressed to 80 KB. Steps: (1) Open the appropriate tool; (2) Drop the file; (3) Select the compression preset or set a target size (e.g., "Target: 100 KB"); (4) The tool compresses and previews the result; (5) Download. All processing is local — no waiting for server queues, no file size limits on upload.

How do I handle password-protected PDFs?

Many official PDFs are password-protected: e-Aadhaar PDFs from UIDAI, PAN card PDFs from Protean/NSDL, ITR acknowledgements from Income Tax portal, and bank statements. DocEasy's ID Card Cropper handles password-protected PDFs natively using PDF.js. Common password formats: Aadhaar e-PDF: First 4 letters of name in CAPITALS + birth year (e.g., "DEEP1998"). PAN card: Date of birth in DDMMYYYY (e.g., "15011998"). ITR: PAN number in lowercase + DOB DDMMYYYY (e.g., "abcde1234f15011998"). Bank statements: Varies by bank (often customer ID or DOB). If you don't know the password, ask the customer — they usually have it in the email they received. The tool handles all standard PDF encryption without needing external software.
