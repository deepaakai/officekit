What is PDF Merging?

PDF merging is the process of combining two or more separate PDF files into one single document, preserving the original formatting, fonts, images, and page structure of every source file. Unlike converting formats or editing content, merging simply appends pages from one document to another in a specified order.

The resulting file behaves as a single PDF with continuous page numbering, but each original page retains its unique dimensions, embedded fonts, hyperlinks, and metadata. This makes PDF merging ideal for reports, contracts, portfolios, scanned archives, and academic submissions where preserving the original document integrity is critical.

How Does the Merge Algorithm Work?

When you click "Merge PDFs Now," the tool performs a series of operations entirely in your browser:

  1. Read each PDF: Every file is loaded into memory as a binary buffer.
  2. Parse the PDF structure: The engine extracts page objects, embedded resources, fonts, and metadata.
  3. Create a new document: An empty PDF document is initialized in memory.
  4. Copy pages sequentially: Pages from each source file are copied in order using the copyPages method, which preserves cross-references and object streams.
  5. Write the output: The final document is serialized into a binary PDF, then offered as a downloadable Blob.

Because every step happens locally, no network requests occur during the merge process. You can even disconnect from the internet after loading the page and the merge will still work.

Use the Compress PDF tool after merging to reduce the file size without losing readability.

Some pages appear rotated

This is typically a rotation metadata issue in the source files, not the merge itself. Open the source PDF in any viewer and rotate the pages, then re-upload.

Bookmarks disappeared after merging

Bookmark preservation depends on whether the source PDFs contain bookmarks. DocEasy preserves them when present, but does not generate new ones.

Form fields stopped working

Interactive forms are copied as static objects when merging. If you need editable forms, consider filling them before merging.
